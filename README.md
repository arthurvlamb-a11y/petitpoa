# Petitpoa

Missão

Crie um site premium, moderno e emocional para a Escola de Educação Infantil Petit Poá, localizada no Centro de Estância Velha/RS.

O objetivo principal é fazer com que pais de crianças de 4 meses a 5 anos sintam confiança em menos de 10 segundos e agendem uma visita.

O site deve superar o padrão das escolas infantis brasileiras e ter qualidade visual comparável às melhores referências de design educacional.
